# 잔여수명·이벤트 화면 (2026-10-01)

## 사용 방법

로컬 페이지 `http://127.0.0.1:5173/react-twin/?viewer=ce883`에서 **3월 검사 기록 연결**을 선택한다. 분해(현장 분석) 단계의 첫 화면에 그래프와 이벤트 목록이 표시된다.

- 점 또는 목록 선택: 기록 시각, 관련 부품, Unity 표시 상태, 당시 운전 변수와 상세 설명을 함께 변경한다.
- 선택 날짜 확대: 하루 00:00~24:00로 확대해 가까운 이벤트를 구분한다. 전체 기간으로 복귀할 수 있다.
- 심각도순/최신순 및 상·중·하 필터. 심각도 미확인 기록은 미분류로 유지한다.
- 가상 그래프 예제: 곡선 위 점, 과거 실선·미래 점선, 교체 주기 단절과 부품 선택을 시험한다. 화면에 가상 데이터임을 표시한다.

## 현재 실제 연결 범위

3월 B 파일의 1,036,800초 원본 캐시를 읽기 전용으로 조회한다. 개요에는 5분 간격 점, 마지막 초 및 이벤트의 정확한 시각을 포함해 3,460개 스냅샷을 전달한다. 기존 12월 기록도 별도 버튼으로 유지한다.

2026-03-27의 네 기록을 연결했다.

| 시각(KST) | 내용 | 근거 |
|---|---|---|
|08:00|롤타이어 마모도 측정|정비 이력의 08:00~16:00 검사 기록|
|08:45:24|모터 상태 4 확인|운전 파일에서 처음 관측된 정확한 값 4|
|10:11:41|모터 상태 코드 20 확인|운전 파일에서 처음 관측된 정확한 값 20|
|15:36:52|모터 상태 1 복귀|운전 파일에서 관측된 값 1 복귀|

이는 전체 정비 이력 수집이나 자동 이상 탐지 완성을 의미하지 않는다. 상태 전환 직전 소수값 구간이 있으므로 관측 시각을 실제 기동·정지 순간으로 단정하지 않는다. 코드 20의 구체적 원인은 미확인이다.

실제 잔여수명·마모율 예측 파이프라인은 아직 연결 전이다. 마모 측정값의 의미와 단위, 교체 한계 및 주기 기준의 확인도 필요하다. 따라서 실제 이벤트는 ‘수명값 없는 이벤트’ 시간축에 표시하며 수명 곡선을 만들지 않는다. 검사 기록을 타이어 교체로 처리하지 않는다. 음수 아날로그 값은 물리량 카드에서 결측으로 표시하고 원값 패널에서 그대로 보존한다.

## 데이터 규약

기존 v2 규약에 선택적 `lifeCurves`를 추가했다. 각 곡선은 `componentId`, `zone`, `points`로 구성하고 각 점은 `at`, `remainingDays`, `source`, `cycleId`를 가진다. 설비 전체 곡선은 부품/위치가 null이다. 부품별 곡선이 없으면 설비 기준임을 명시한다.

일수는 제공된 수명 곡선 또는 `replacementAt - at`에서 얻는다. 운전시간을 24로 나누지 않는다. 동일 주기, 유효한 두 점, `maxGapSeconds` 이내에서만 이벤트 위치를 보간한다. 교체 주기·결측·데이터 공백은 선을 연결하지 않는다. 미래 예측의 0일 끝점은 가상 예제의 최신 교체 권장일과 일치한다.

## 검증

- 프런트 계약·수명 보간·API 통합: 25개 통과.
- TypeScript/Vite 빌드 및 CE883 ESLint 통과. 기존 번들 크기 권고 경고는 남아 있다.
- 브라우저에서 실제 검사 시각의 급탄량 41.36 t/h, 저널 압력 1,057.79 psi와 원본 연결 확인.
- 코드 20 이벤트 선택 시 상태 이상, 431.3 MW 표시 확인.
- 가상 이벤트 키보드 선택, 심각도 정렬, 교체 주기 단절, 분해에서만 그래프 노출 확인.
- 좁은 창/1440px 배치 확인. 검증 후 브라우저 크기는 원래대로 복원.
