## 산출물과 한계

상세 한 대는 약 197,560 triangles / 484 renderers. 외형 6대는 세부 내부를 제외한 메시를 재질별로 결합·공유하며 상세 모델과 교대로 표시한다. 실제 현장 좌표 배치가 아닌 탐색용 배치다.

WebGL 약 59.8 MB, 로컬 확인용 무압축. 운영용 압축·캐시·인증 및 A~F 데이터 어댑터는 별도 연결 범위다. 모바일 장시간 성능·메모리 스트레스 테스트는 수행하지 않았다.

`Evidence/ce883/depth-fleet-scenario.png`, `depth-cutaway-scenario.png`, `depth-event-scenario.png`는 가상 UI 시험 화면이다. 실제 상태·수명·절감 효과의 증거가 아니다.

실제 A~F 운영 기록, RUL 예측 정확도, 이벤트 인과 효과, 현장 계측 방향, 마모 깊이 형상 변형은 검증하지 않았다. 발견한 데이터 컬럼과 누락 항목은 CE883_DATA_AUDIT.md 참조.

Vite는 기존 앱과 합친 JS 청크 500 kB 초과 경고를 남긴다. Unity URP의 미사용 FSR 셰이더 경고는 존재하나 기본 렌더링은 확인했다. 로컬 서버 종료로 발생한 연결 실패는 재시작 후 새 탭에서 정상 실행을 확인했다.

## 최종 오류 수정 재검증

검증용 임시 Fleet가 씬에 남지 않도록 생성 소유 관계와 명시적 정리를 수정했다. 저장된 씬의 FleetOverview_A_to_F 잔여 루트는 0개다. 런타임 상태등은 SphereCollider가 필요한 CreatePrimitive 대신 충돌체 없는 공유 구 메시를 사용한다. 최종 새로고침 로그에서 level0 손상 및 SphereCollider/NullReference 오류가 사라졌고, 6대 표시와 B 직접 클릭 → 절개 전환을 다시 확인했다. 미사용 FSR 셰이더 경고는 남아 있다.

빌드 해시 버전 파일로 Unity 리소스를 함께 갱신한다. 씬 ready 이벤트가 오지 않을 때도 100% 로딩에 무한 정체하지 않고 초기화 오류를 표시한다. 최종 기본 화면 증거: Evidence/ce883/depth-overview.png. 테스트 후 가상 데이터를 제거하고 외형 상태로 복귀했으며 뷰포트 설정을 복원했다.
