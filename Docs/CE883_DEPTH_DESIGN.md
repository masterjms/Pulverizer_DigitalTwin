# 미분기 정보 깊이 3단계 — 2026-09-27

사용자 요청이 이전 기획서의 역할별 4단계 설계보다 우선한다. 역할로 화면을 잠그지 않고 외형 → 절개 → 분해의 깊이에 따라 같은 데이터의 상세도를 바꾼다.

| 깊이 | Unity | React의 주된 질문 | 공통 맥락 |
|---|---|---|---|
| 외형 / 운영 총괄 | A~F 6대의 경량 외형, 설비 클릭 | 가동/정지/확인 불가, 당일 발전 목표 달성률, 기존 방식 대비 비용 | 발전소·기준시각·출처 |
| 절개 / 교체 계획 | 선택 설비 1대 절개 | 마모·마모율·잔여 운전시간·교체권장 시점, 20,000h 관행 비교, 정비 이력 | 선택 설비·과거 재생 시각 |
| 분해 / 현장 분석 | 선택 설비 분해, 롤/위치 선택 | 누적 마모(mm)-시간 선 그래프와 이벤트 점, 3×10 위치, 운전 변수, 이벤트 전후 변화·상관분석 근거 | 동일 시점·출처·교체 판단·정비 이력 |

외형에서 설비 클릭 → 절개. 절개에서 롤 클릭 → 분해 상세. 단계 버튼과 되돌아가기는 항상 제공한다. 롤/구간 확대는 분해 단계 안의 선택 상태이며 별도 네 번째 단계가 아니다. 설비·단계 변경으로 과거 커서를 현재 시각으로 몰래 바꾸지 않는다.

## 화면 설계

기존 설비색과 다크 계기판을 유지한다: 바탕 #12202b, 패널 #21323e, 구조선 #456071, 본문 #dfe8ed, 측정/운전 #33a392, 주의·가정 #d6a348. 맑은 고딕/Segoe UI. 수치는 단위와 함께 표시하고, 과거/가상 데이터는 화면 상단에 명확히 표시한다.

상단: 설비 경로·3단계 탐색·기록 입력. 중앙 왼쪽: Unity. 오른쪽: 단계별 의사결정 정보. 절개/분해의 Unity 아래: 과거 기록 재생 타임바. 분해 하단: 이벤트-마모 그래프와 이벤트 상세/정비 이력. 동일한 카드 반복보다 모델·시간축·판단 정보의 위치를 고정한다. 좁은 창에서는 모델, 판단, 시간축/그래프 순으로 세로 배치한다.

## 데이터 원칙

- 실제 DB 서버에는 접속하지 않고 로컬 스키마·태그 정의를 조사한다. 스키마 존재와 실제 레코드 확보를 구분한다.
- RUL/교체일/마모율은 백엔드 산출값을 받는다. 20,000h는 사용자 지정 관행 비교 기준이며 달력 20,000시간으로 교체일을 만들지 않는다.
- 마모(mm, 누적 깊이), 마모율(µm/h), 한계 대비 비율(%)은 다른 지표다. 첨부 그래프의 하강 곡선을 누적 마모 증가 그래프로 오인하지 않는다.
- 과거 재생은 기록된 스냅샷 재생이다. 새로운 운전 조건의 미래 시뮬레이션과 구분한다. 허용 간격보다 오래된 스냅샷은 현재값처럼 유지하지 않는다.
- 이벤트 동시 발생은 인과관계가 아니다. 전후 마모율·효율 변화 또는 상관계수는 서버 근거가 있을 때만 표시한다.
- A~F에 B의 값을 복제하지 않는다. 누락은 확인 불가/미연결이며 정상·0으로 바꾸지 않는다.
- 생산 목표 MWh는 발전소 3호기 일일 기준이다. MW는 순간 발전출력이고 A~F의 공통 발전출력을 합산하지 않는다.
- `MOTOR_POWER`는 원본 태그 설명서상 A(전류). 전력비 계산에 사용하지 않는다. 저널 압력은 psi로 표시한다.
- UI 검토용 시나리오는 명시적으로 여는 별도 예제이며 운영 값으로 자동 폴백하지 않는다.
