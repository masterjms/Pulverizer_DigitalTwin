## 사용 순서

1. 외형: 6대 상태와 발전 목표·운영 비용을 확인한다. 데이터가 없으면 확인 불가/미산정이다.
2. 설비를 클릭하면 절개로 진입한다. 교체 권장일·잔여 운전시간·마모율·20,000 h 비교와 정비 이력을 본다.
3. 롤 접촉면을 클릭하거나 롤 상세 버튼을 누르면 분해 단계의 부품 확대와 상세 분석으로 진입한다. 분해 전체로 버튼으로 전체 부품 관계를 볼 수 있다.
4. 타임바로 기록 시점을 바꾸거나 재생한다. Unity 색과 가동 상태, React 값, 정비 이력이 함께 바뀐다.
5. 마모 그래프의 이벤트 점을 누르면 해당 시점과 부품으로 이동한다. UI 위치 1~10을 누르면 Unity의 같은 위치가 선택된다.
6. 상단 외형·절개·분해 버튼으로 언제든 이동한다. 역할에 따라 잠기지 않으며 기준 시점을 유지한다.
7. 드래그는 회전, 휠은 모델 확대, Escape는 외형 복귀다. 페이지 스크롤은 모델 바깥에서 한다.

기본값은 실제 데이터 미연결이다. **데이터 연결 → 가상 UI 예제 열기**를 누르면 24일 시험 기록으로 화면 동작을 확인할 수 있다. 상단에 가상 데이터 안내가 표시된다. 예제 닫기로 시험값을 모두 지운다. 예제의 비용·목표·수명·이벤트는 실제 분석 결과가 아니다.

검증된 실제 기록은 기록 불러오기(JSON) 또는 동일 출처 읽기 API로 연결한다. B 데이터는 A~F에 복제되지 않는다. 타임바는 과거 상태 재생이며 운전 조건을 변경하는 미래 계산 시뮬레이터는 아니다.

확인한 로컬 스키마에는 발전소 순간 출력 MW는 있으나 일일 목표 MWh, 누적 발전 실적 MWh 및 비용 단가·정비비 컬럼은 없다. MOTOR_POWER는 정의서의 A와 실제 B 엑셀의 CU.M/H가 충돌하므로 단위 미확정으로 처리한다. 상세 근거와 필요한 항목은 `CE883_DATA_AUDIT.md`, 후속 실측 연결은 `CE883_LOCAL_B_DATA.md`에 정리했다.
