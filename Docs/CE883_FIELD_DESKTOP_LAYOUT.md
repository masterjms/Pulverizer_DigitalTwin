# 분해 단계 PC 배치

2026-10-01

사용자 참조 그림에 맞춰 분해 단계만 조정했다. 외형·절개 단계는 기존 배치를 유지한다.

- 폭 1200px 이상, 높이 680px 이상에서 브라우저 뷰포트에 맞춘 고정 작업 화면을 사용한다. 그보다 작은 화면/확대된 브라우저에서는 내용 접근을 위해 일반 페이지 스크롤을 허용한다.
- 위쪽 왼쪽: 선택 롤 하나를 확대하는 Unity 창. 롤 1/2/3 선택 버튼 제공. 분해 진입 시 선택이 없으면 롤 1을 표시한다.
- 위쪽 가운데: 미래 시뮬레이션 검토 자리. 안내만 표시하며 계산 기능은 구현하지 않았다.
- 모델 아래: 과거 기록 타임바, 그 아래 잔여수명 그래프와 이벤트 목록.
- 오른쪽: 선택 설비, 이벤트 상세, 교체 판단, 원본 운전 기록, 위치별 마모, 운전 변수, 정비 이력. 독립 스크롤과 키보드 포커스를 제공한다.
- 이벤트가 많을 때 목록 자체에서 스크롤한다. 차트·모델·타임바는 제자리에 유지한다.
- 그래프 좌표는 실제 표시 영역 크기에 맞춰 재계산하여 작은 화면에서 SVG 전체 축소로 글씨가 지나치게 작아지는 문제를 방지한다.

## 확인 결과

| 크기 | 문서 스크롤 크기 | 결과 |
|---|---|---|
|1920×1080|1920×1080|전체 페이지 스크롤 없음|
|1366×768|1366×768|전체 페이지 스크롤 없음, 그래프 높이 189px|

오른쪽 패널에서 Ctrl+End 후 패널만 스크롤되고 페이지 Y=0 유지 확인. 곡선 이벤트 선택 시 오른쪽 상세와 롤 위치 선택 연동 확인. 절개 단계에서 고정 화면 클래스 해제 및 상세 패널의 일반 흐름 복원 확인. 계약·API 테스트 25개, 빌드, CE883 ESLint 통과. 기존 번들 크기 권고 경고는 유지된다.

화면 증거는 `Evidence/ce883/field-desktop-1920.png`, `field-desktop-1366.png`이며 가상 UI 예제로 배치를 검증한 화면이다.

미래 기능 제안은 `CE883_FUTURE_SIMULATION_PROPOSAL.md`를 참고한다.
