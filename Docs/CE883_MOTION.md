# Unity 화면 전환 — 2026-09-29

- 외형 → 상세: 선택 설비의 외형 위치를 상세 모델이 이어받고 중앙으로 이동한다. 나머지 설비와 바닥 크기는 같은 전환 진행률로 변한다.
- 카메라: 1.25초 동안 목표점·거리·방위각·고도를 보간한다. 시작과 끝에서 속도/가속도가 0이 되는 곡선이며, 방위각은 짧은 방향으로 회전한다.
- 절개: 외피 조각이 이동하며 축소되어 내부를 드러낸다.
- 분해: 상부 분리기가 1.8m 상승하고 롤 3개가 바깥으로 펼쳐진다. 약 0.95초 연출이며 물리/마모 계산에 사용하지 않는다.
- 부품 선택: 주변 조립체를 접으면서 선택 롤로 확대한다. 외형으로 복귀하면 원래 위치·크기·표시 상태를 복원한다.
- 연속 입력: 진행 중인 현재 위치에서 새 목표로 다시 이동한다. 코루틴을 쌓거나 이전 전환 완료 콜백이 최신 선택을 덮어쓰지 않는다.
- 드래그/휠 입력: 카메라 자동 이동을 중단하고 사용자가 이어서 조작한다. 움직이는 중의 모델 클릭은 무시하며 단계 버튼은 계속 사용할 수 있다.
- 운영체제/브라우저의 `prefers-reduced-motion` 설정은 즉시 전환으로 처리한다. 변경 시에도 적용된다.
- React 캔버스 영역 높이도 동일한 시간 동안 변해 화면 크기의 급변을 줄였다.

구현: `TwinOrbit.cs`, `TwinModel.cs`, `TwinFleet.cs`, `TwinBridge.cs`; React의 `useDepthUnity.ts`, `depth.css`.

`Ce883Builder.Verify`에서 카메라/분해 중간 위치, 시작 위치 유지, 전환 역전, 모델 복원, 부품 단독 표시를 검증한다. 로그 표식은 `NEXTRO_MOTION_VERIFY_PASS`이다.

운전 기록과 마모 계산식은 변경하지 않았다. 이 움직임은 화면 탐색 연출이며 실제 설비 동작/실측 회전수를 뜻하지 않는다.
