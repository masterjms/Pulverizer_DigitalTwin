# 미분기 미래 시뮬레이션 화면 제안

2026-10-01 · 조사·설계안만 작성. 시뮬레이션 기능은 구현하지 않음.

## 권장 방향

분해 화면의 모델 옆 공간에는 **운전 조건별 수명 비교**를 배치한다. 조건 입력과 결과 요약은 위 공간, 결과 곡선은 이미 있는 아래 그래프, 상세 가정과 근거는 오른쪽 패널에서 확인하도록 한다. 작은 영역에 또 다른 그래프를 추가하기보다 같은 시간축에서 현재 운전 유지와 대안을 비교한다.

과거 재생은 기록을 조회하는 행위이고 미래 시뮬레이션은 가정을 넣어 계산하는 행위다. 두 모드는 이름·시간 커서·상태 표시를 분리한다. 과거 검증 모드에서는 기준일 이후 데이터를 예측 입력에 사용하지 않는다.

## 제안 UI 흐름

1. **기준 상태 선택:** ‘2026-03-27 검사 이후’처럼 기준일, 측정 반영 여부, 모델 버전과 선택 롤을 고정한다. 검사 전 상태와 이후 측정을 혼합하지 않는다.
2. **비교 기간 선택:** 30/90/180일. 하루 예상 운전시간과 운전 조건 유지 여부를 명시한다. 운전시간과 달력일을 구분한다.
3. **대안 설정:** 처음에는 급탄량 또는 저널 압력 등 검증된 마모 모델이 실제로 사용하는 입력만 노출한다. 3호기 발전 출력 목표를 B 한 대의 급탄량에서 바로 산출하지 않는다. 석탄 품질 등 통제하기 어려운 입력은 ‘가정’으로 구분한다.
4. **계산 실행:** 입력별 허용 범위·단위와 학습/검증 범위를 표시한다. 범위 밖 계산은 외삽임을 명시하고 검증 수준에 따라 제한한다. 운전 제어 명령은 보내지 않는다.
5. **결과 비교:** 같은 기준 상태에서 ‘현재 운전 유지’와 ‘조건 변경안’의 교체 권장일 차이, 최대 위치 마모, 누적 처리량을 비교한다. 계산 가능한 항목만 표시한다.
6. **미래일 탐색:** 아래 그래프의 미래 커서를 움직이면 Unity의 1~10 위치 색과 오른쪽 상세 값이 해당 대안·미래일의 예측 상태로 바뀐다. 항상 ‘예측’ 배지를 유지한다.

공간별 배치:

```
작은 부품 모델  | 기준일 / 비교 기간 / 기준 운전 vs 대안
               | 변경 조건 1~2개 / 계산 / 결과 차이 요약
과거 재생 또는 미래일 탐색 타임바
이력 실선 + 기준 예측 점선 + 대안 예측 점선 | 이벤트 목록
                                    오른쪽: 상세·근거 내부 스크롤
```

## 어떤 실험부터 만들 것인가

### 1순위: 현재 조건 유지 vs 조건 변경
‘급탄 조건을 바꾸면 수명이 얼마나 달라지는가?’를 답하는 핵심 실험. 단, 운전 변수와 마모의 상관만으로 제어 변경의 인과 효과를 보장할 수 없다. 검증된 모델과 가정 범위가 먼저 필요하다.

### 2순위: 정비 시점 비교
‘현재 계획대로 교체’와 ‘점검 후 연장’ 등의 시나리오를 비교한다. 정지 기간·부품비·노무비·전력 단가가 확보된 뒤 비용을 계산한다. 지금은 비용 데이터가 없으므로 금액을 만들지 않는다.

### 3순위: 민감도/불확실성
어떤 변수가 결과를 크게 바꾸는지 범위 실험으로 비교한다. 신뢰구간은 모델 검증과 오차 자료가 확보된 경우에만 제공한다. 처음부터 여러 슬라이더를 모두 노출하면 결과 해석과 인과 판단이 어려워진다.

## 선행 조건과 구현 경계

- 실제 B의 잔여수명 예측 파이프라인 연결과 과거 시점 검증.
- 마모 측정값의 의미·단위·부품/위치 방향, 교체 한계 및 교체 주기 기준 확인.
- 입력 변수 단위 정합성과 결측·정지 구간 처리.
- 모델 입력별 변화가 결과에 반영되는지 검증. 모형에 없는 변수는 장식용 슬라이더로 노출하지 않음.
- 결과 저장 시 기준 스냅샷, 모델 버전, 입력 조건, 계산 시각, 데이터 출처를 묶어 재현 가능하게 관리.
- 화면 배치 작업에서는 미래 시뮬레이션 영역에 검토 중 안내만 두었다. 실행 버튼·가상 예측 수치·임의 비용은 추가하지 않았다.
